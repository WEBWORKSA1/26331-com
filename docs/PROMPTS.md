# 26331.com — Phase-wise Build Prompts

Copy each prompt into your AI builder in order. Each phase ends with a testable result. This repo is the finished output of these prompts.

**Constants used in every phase**
- Domain: `26331.com` · Brand: **26331 Numbers Lab** · Story: _26 tools · 3 hubs · 31-day plan_
- AdSense: `<script async src="https://pagead2.googlesyndication.com/pagead/js/adsbygoogle.js?client=ca-pub-6620975821265271" crossorigin="anonymous"></script>`
- Top bar on every page: "Contact, if you are interested in this website/domain name/Sponsorship/Advertisement/Partnership" → links to the inquiry page; the URL text is never shown.
- All forms deliver to the single site inbox via a form service; the address is never visible in page text (assemble it at runtime).
- Hosting: GitHub Pages, free plan, `main` branch, root folder. No server code.

### Phase 1 — Foundation & design system
> Build a static site skeleton for 26331.com, "26331 Numbers Lab", a free calculator hub for money, business and AI decisions. Use plain HTML, one CSS file and vanilla JS (no frameworks, no build step at runtime). Create a Python build script that wraps page bodies in `src/` with a shared layout (head with SEO meta, canonical, Open Graph, JSON-LD, the AdSense script, Google Fonts "Space Grotesk" + "JetBrains Mono"; sticky header with logo badge "26331", nav: Tools, Number Explorer, AI Hub, Learn, Videos, Community, Support, CTA "Free Growth Review"; a dark inquiry bar above the header; a 4-column footer with a trademark/copyright note). Design: ink navy #0d1321, paper #f7f5ef, lime accent #c6f432, mono numerals, 16px radius cards, mobile hamburger menu, reveal-on-scroll animation that respects reduced-motion. Make it fully responsive at 960px and 620px breakpoints.

### Phase 2 — The 26 calculators
> Create `js/tools.js` with a data-driven engine: each tool = {id, category, icon, name, description, fields[], run()}. Render cards with forms, a dark result panel (aria-live) and a "get a free review" CTA that appears after a result. Add search and category chips (All, Money, Business, AI, Numbers) and deep links (#id). Build these 26 tools: **Money (9):** loan/EMI, mortgage with tax+insurance, compound interest with monthly contributions, savings goal, inflation, currency converter (reads daily rates from `data/daily.json`), credit card payoff, FIRE number, tip & bill split. **Business (9):** profit margin, break-even, price-from-target-margin, ROI (total + annualised), LTV:CAC with 3:1 verdict, startup runway with revenue growth, freelance hourly rate, sales tax/VAT add/remove, discount impact. **AI (4):** AI API cost from tokens and per-million prices, AI time-savings ROI, word↔token estimator, AI vs new hire. **Numbers (4):** number to words/cheque writer, prime factorization, base converter (+Roman), percentage calculator. Validate inputs and guard against divide-by-zero.

### Phase 3 — Number Explorer (domain-native feature)
> Create `number.html` and `js/numbers.js`. User enters any whole number (default 26331, also read from the URL hash) and gets 16 fact tiles: words, prime factors, divisor count, perfect/abundant/deficient, digit sum and digital root, palindrome, binary, octal, hex, base 36, Roman, square, square root, phone-keypad letters, reversed, cheque wording. Update the hash so results are shareable. Add a 400-word original explainer about 26331 (3 × 67 × 131, 8 divisors, hex 66DB) and why number facts matter in business. Don't imply any affiliation with organisations using the same digits.

### Phase 4 — Lead generation engine
> Build `grow.html`: a 3-step form with a progress bar — (1) goal as radio cards: funding, website, AI automation, marketing & leads, pricing & profit, domain/brand; (2) stage, budget, timeline; (3) name, company, email, phone, country, details, consent checkbox. Validate each step before advancing. Add: a short lead form on the homepage, a CTA under every calculator result, a sticky "Free growth review" button after 900px of scrolling, and a once-per-visitor exit-intent/35-second popup offering the "31-Day Numbers-First Growth Plan". All forms post JSON to the form service with a subject prefix "[26331.com]", a honeypot field, inline success/error messages, and no page reload.
